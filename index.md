# Privacy Policy — Sanchay

Last updated: July 30, 2026

Sanchay is a browser extension that lets users save YouTube channels,
videos, and playlist intentions for later action.

## What Sanchay stores

Channel names, video titles, URLs, playlist names, and timestamps you
choose to save, kept in your browser's local storage
(chrome.storage.local). This data never leaves your device except as
described below.

## What Sanchay does not do

Sanchay does not collect, transmit, sell, or share any personal data,
browsing history, or YouTube account information with any server,
developer, or third party. Sanchay has no backend server of its own.

## Network activity

The only actions Sanchay takes on the network are the ones it was built
for, opening YouTube pages in a browser tab and clicking buttons
(Subscribe, Like, Save to playlist) on the user's own already signed in
YouTube session during the Sync All process. This is the same as the
user manually clicking those buttons themselves.

## Permissions

See the extension's Chrome Web Store listing for a description of why
each permission is requested.
